# The Constitution Builder · short demo

A 1.5-minute version of the DDW demo for presentations, by Femke Veenvliet.

1. **The conversation**: one real person from the user test (the self-focused profile), with their own constitution, side by side with the same AI without one. Message by message, with the passages that matter highlighted.
2. **The three profiles**: how each of three real people's AI ended the same conversation, and why.

Everything shown is real: the recordings and constitution lines come unchanged from the full demo (`data.js` is generated from it).

## Presenting

- Open `index.html` (or the GitHub Pages link) and press **F** for full screen.
- Next: click the button, or **→**, **Space** or **Page Down** (a presentation clicker works). Back: **←** or **Page Up**. Start over: **Home**.
- 8 steps: send the first question, five more messages, then the three profiles.
- It also works offline: open `index.html` straight from the folder.

The page is a fixed 1920 × 1080 canvas that scales to fit any screen.

## On GitHub Pages

Repository → Settings → Pages → Source: *Deploy from a branch* → `main`, folder `/ (root)` → Save. The site appears at `https://<username>.github.io/<repository>/` after a minute.
